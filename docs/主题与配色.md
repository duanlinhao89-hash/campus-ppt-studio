# 主题与配色

工具内置四套主题。每套主题遵循同一设计原则：**一个主色 + 一个强调色 + 中性色**，克制、耐看、适合投影。

---

## 内置主题

| key | 名称 | 适合 | 主色 | 强调色 |
|---|---|---|---|---|
| `academic` | 学术蓝 | 毕业答辩、学术汇报 | 深蓝 `#1F3A5F` | 亮蓝 `#2E6FB7` |
| `fresh` | 清新绿 | 教学课件、科普 | 深绿 `#1E6B54` | 中绿 `#3FA07C` |
| `vital` | 活力橙 | 班级活动、社团 | 橙棕 `#C85A17` | 亮橙 `#E8873A` |
| `ink` | 墨韵灰 | 说课、正式汇报 | 深灰 `#2E3338` | 砖红 `#B4472F` |

查看全部主题：

```bash
python -m campus_ppt themes
```

使用主题（两种方式）：

```bash
# 方式一：在大纲元数据里写
# theme: fresh

# 方式二：命令行覆盖
python -m campus_ppt build 大纲.md -o 输出.pptx --theme fresh
```

---

## 主题影响什么

一套主题会统一应用到：

- **封面 / 章节页 / 致谢页**的满屏背景色
- **标题装饰条、序号圆点、时间轴节点**的强调色
- **正文、副标题、页脚**的文字颜色
- **数据卡、双栏卡片**的浅色底
- **所有文字的中英文字体**

## 自定义主题（进阶）

主题的定义在 `campus_ppt/themes.py`。你可以新增一套 `Theme`：

```python
Theme(
    key="ocean",
    name="海洋蓝",
    description="清爽的海洋主题",
    primary="0B3C5D",     # 主色
    accent="328CC1",      # 强调色
    ink="1B2A38",         # 正文深色
    muted="6E7F8D",       # 辅助灰
    bg="FFFFFF",          # 页面背景
    surface="EEF4F8",     # 卡片浅底
    on_primary="FFFFFF",  # 主色背景上的文字
    cn_font="微软雅黑",
    en_font="Calibri",
)
```

注册到 `THEMES` 字典后，即可通过 `--theme ocean` 使用。

配色建议：

1. 主色和强调色要**同色系但有明度差**，不要撞色到刺眼；
2. `on_primary` 要与主色有足够对比度（通常白或近白）；
3. `surface` 取主色的极浅版本（接近白），用于卡片底；
4. 中文 PPT 建议字体用「微软雅黑」或「思源黑体」，跨平台可用「苹方」。

欢迎把你设计的主题通过 PR 贡献进来！
